# Indoor – App (Kontrolör Yazılımı)

Yeni sürümü bu klasöre ekleyin.

1. **Add file → Create new file**'a basın. Ad kutusuna sürüm numarası ve `surum.json` yazın, örneğin `2.1.2/surum.json`.
2. İçine şunu yapıştırın, düzenleyin ve **Commit changes**'e basın:

```json
{
  "tarih": "2026-11-23",
  "durum": "kararli",
  "notlar": [
    "Bu sürümde ne değişti, kısaca yazın."
  ]
}
```

3. Oluşan sürüm klasörüne girin, **Add file → Upload files** ile dosyayı yükleyin ve **Commit changes**'e basın.

`durum` değerleri: `kararli` (sitede son sürüm olur), `test` (sadece geçmişte görünür), `geri-cekildi` (kullanılmaz olarak işaretlenir).
