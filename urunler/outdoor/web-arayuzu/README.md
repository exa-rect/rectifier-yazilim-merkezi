# Outdoor – Web Arayüzü

Yeni dosyayı bu klasöre yükleyin: **Add file → Upload files** → dosyayı sürükleyin → **Commit changes**.

- En son yüklenen dosya sitede **son sürüm** olur, 1–2 dakika içinde görünür.
- Sürüm numarası dosya adındaki `V` numarasından okunur (örn. `_V213.7` → v213.7).
- Eski dosyalar silinmezse sitede geçmiş listesinde kalır.
- Yeni dosya sorunluysa silin; bir önceki dosya yeniden son sürüm olur.
